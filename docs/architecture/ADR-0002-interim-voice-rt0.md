# ADR-0002 — Interim voice for RT0

Status: Accepted by owner, 2026-10-14 (Canon Amendment A1).

RT0 can close with a declared INTERIM voice, not a falsely ACCEPTED voice. Only subjective voice similarity/naturalness acceptance is deferred to RT1; real audio, stop, synchronization, latency, cost, consent and privacy remain mandatory. Standalone TTS receives a versioned binding within provider-state and any profile/voice change changes digest. Integrated speech without standalone TTS remains valid. RT1 requires ACCEPTED profile, rights and both owner and independent human listening evidence. No alternate silent fallback in strict release evidence.
