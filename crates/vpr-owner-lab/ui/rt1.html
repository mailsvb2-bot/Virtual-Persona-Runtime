Persona · RT1

Локальная проверка публикации и связи с посетителем. Диагностический WebRTC-тракт не является сгенерированным видео Persona.

Создать свою Persona и кабинет

Пройдите интервью, затем подтвердите каждое утверждение. Только после подтверждения сервер создаст отдельного владельца и закроет Persona для редактирования без авторизации.

Новая Persona создаётся отдельно от остальных аккаунтов.

Ключ кабинета показывается только при завершении регистрации. Сохраните его в менеджере паролей; он не хранится в браузере.

Владелец

Создайте доступ один раз после проверки Persona. Сохраните ключ владельца в надёжном месте — он не сохраняется в браузере.

Введите ключ владельца для загрузки текущей версии и статуса.

Ссылка работает только на том же локальном адресе Owner Lab. Это не публичная публикация и не доступ с другого устройства.

Посетитель

Введите код приглашения и подключитесь. Микрофон включается только по вашему действию «Говорить». Камера посетителя не передаётся.

Моя память

Память хранит только текстовые заметки. Ключ личный: это не код приглашения. Не делитесь им и сохраните в защищённом менеджере паролей. Без ключа память нельзя восстановить.

Секрет показывается только при создании и остаётся в поле ввода до закрытия страницы. Для другого устройства перенесите его самостоятельно.
