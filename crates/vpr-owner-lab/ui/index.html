Видео появится после подключения realtime-транспорта

Visitor-сессия использует ту же Persona, но не получает owner-reviewed личный контекст. Текстовый и голосовой разговоры остаются visitor-scoped; прямой avatar speak не используется как разговор.

Сообщение идёт через canonical Persona → LLM turn. Первый непустой streaming-ответ измеряется на backend и попадает в sanitized evidence без текста сообщения или ответа.

Выберите конкретное устройство ввода, если Chrome использует не тот микрофон. Названия устройств могут появиться только после разрешения доступа к микрофону.

Push-to-talk: микрофон обрабатывается в браузере и отправляется как PCM только после остановки записи.
